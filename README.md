# Gessé Soares

Essa é a minha landing. Tem um oi e um botão para baixar o currículo, em português ou em inglês.

https://gessemacedo.github.io/gesse-soares/

## Idioma

A página abre em português. Se quiser inglês, clica em EN. Para voltar, clica em PT. Eu lembro a sua escolha neste navegador: se você sair e voltar, ela abre no último idioma.

## Ver localmente

É HTML estático. Abre o `index.html` no navegador, ou sobe um servidor estático simples na pasta do repositório.

## Publicação

O GitHub Pages publica a partir da branch `main`.

The English version is the same page. Hit EN.
